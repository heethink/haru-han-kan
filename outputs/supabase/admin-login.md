# 관리자 발급 아이디 계정 만들기

## 아이디 규칙

- 아이디는 영문자, 숫자, 점(`.`), 밑줄(`_`), 하이픈(`-`)만 사용하고 3~32자로 정합니다.
- 대문자와 소문자는 같은 아이디로 취급합니다.
- 기존 이메일 계정은 이메일 주소로 계속 로그인할 수 있습니다.

## Supabase에서 계정 준비

1. Supabase 대시보드에서 `moabom-photo-curation` 프로젝트를 엽니다.
2. 공개 가입을 막으려면 Authentication 설정의 **User Signups → Allow new users to sign up**을 끕니다. 이미 만든 사용자는 계속 로그인할 수 있습니다.
3. **Authentication → Users**에서 새 사용자를 추가합니다.
4. 이메일 칸에는 `<아이디>@login.haru-han-kan.invalid` 형식으로 입력합니다. 예를 들어 아이디가 `class-01`이면 `class-01@login.haru-han-kan.invalid`입니다.
5. 사용자가 로그인할 비밀번호를 지정하고, 이메일 인증 완료(confirmed) 상태로 생성합니다.
6. 아이디와 임시 비밀번호를 해당 사용자에게 안전한 방법으로 전달합니다.

`.invalid` 주소는 실제 메일 수신용이 아닙니다. 따라서 비밀번호를 잊으면 관리자가 Supabase 대시보드에서 새 비밀번호를 지정해야 합니다. 실제 메일 주소를 사용하는 기존 계정은 기존 로그인 방식을 유지합니다.

## 접근 제어

사이트에서는 공개 회원가입을 제공하지 않습니다. 관리자 계정 추가는 Supabase 대시보드에서만 합니다. 각 계정에는 Supabase 사용자 ID가 따로 부여되며, `notes` 테이블의 기존 RLS 정책이 사용자 ID별 메모 접근을 제한합니다. 브라우저에는 publishable 키만 사용하며 관리자 키를 추가하지 않습니다.
